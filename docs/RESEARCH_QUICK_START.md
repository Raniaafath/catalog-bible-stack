# 🔍 Research Features - 60 Second Guide

## What's New?

### 1. Search 3 Ways
Type to search in:
- ✅ **Code** (color, size, material)
- ✅ **Name** (Product Color, Item Size)
- ✅ **Description** (full explanation)

### 2. Hover for Details
Hover over any attribute to see:
- ✅ Full name
- ✅ Complete description
- ✅ Data type
- ✅ Translatable status

### 3. Help Icon
Click ❓ to learn about search capabilities

---

## Quick Examples

### Find Color Attribute
```
1. Type: "col"
2. See: color, collection, collar_type
3. Hover: Read description
4. Click: Select color
```

### Find by Purpose
```
Search: "variation" → Finds variation-related attributes
Search: "price" → Finds pricing attributes
Search: "translate" → Finds translatable attributes
```

### Multilingual
```
Search: "couleur" → Finds color (if in name/description)
Search: "taille" → Finds size
Search: "col" → Works in any language
```

---

## Pro Tips

1. **Start short** - Type 3-4 letters
2. **Hover before selecting** - Verify it's right
3. **Read the tooltip** - Check data type
4. **Use partial terms** - "col" finds color, collection
5. **Search by purpose** - "variation", "dimension"
